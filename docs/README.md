# Documentation

Living documentation is organized by responsibility:

- `product/` — vision, scope and roadmap.
- `discovery/` — naming, competitor and feasibility discovery.
- `research/` — sourced platform/ecosystem research and research standards.
- `architecture/` — current architecture, protocols, data model and ADRs.
- `security/` — threat model, permissions, privacy and abuse cases.
- `testing/` — future validation strategy, table-top exercises and acceptance criteria.

Historical generated reports and datasets belong under `artifacts/`, not here. Living documentation should summarize the current accepted understanding and link back to relevant snapshots where useful.
