# Documentação

A documentação viva é organizada por responsabilidade:

- `product/` — visão, escopo e roadmap;
- `discovery/` — naming, concorrentes e viabilidade;
- `research/` — pesquisa fundamentada de plataformas/ecossistema e padrões de pesquisa;
- `architecture/` — arquitetura atual, protocolos, modelo de dados e ADRs;
- `security/` — threat model, permissões, privacidade e abuse cases;
- `testing/` — estratégia futura de validação, tabletop exercises e critérios de aceite;
- `history/` — narrativa que explica a evolução do projeto e das principais decisões.

Relatórios e datasets históricos gerados pertencem a `artifacts/`, não aqui. A documentação viva deve resumir o entendimento atualmente aceito e apontar para snapshots relevantes quando necessário.

## Idioma

Nomes de arquivos e diretórios permanecem em inglês. O conteúdo documental mantido pelo projeto deve ser escrito em português do Brasil. Consulte `language-and-naming-conventions.md`.

Para proveniência da pesquisa originada no ChatGPT, consulte `../artifacts/provenance/`.
