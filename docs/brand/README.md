## Ideia central

Telechir é um termo técnico histórico associado a um manipulador remoto semelhante a uma mão.

Para este produto, a metáfora é direta:

> **A IA pensa; Telechir é a mão segura que transforma intenção em ação sobre uma máquina.**

## Descriptor
